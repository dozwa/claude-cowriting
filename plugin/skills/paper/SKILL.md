---
name: paper
description: Open a paper by path from any folder, pick a recent one by number, or switch between the projects in the folder. Without arguments it lists recent papers. `upgrade` shows what a workspace from an earlier plugin version lacks, `upgrade apply` adds it.
argument-hint: "[path | number | project name | upgrade [apply] | versioning [git|none]]"
disable-model-invocation: true
---

These commands are answered by the CoWriting plugin's hooks module, instantly and without you. If you are reading this, the module did not answer it: tell the author in one line that the CoWriting plugin needs a restart of Claude Code (or an update), and do nothing else.
